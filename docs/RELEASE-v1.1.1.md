# v1.1.1 — 失败重试

Windows 便携版视频下载器：粘贴 / 拖入媒体直链即可下载；可选装浏览器扩展后，能跟随 Chrome / Edge 当前标签页里正在播放的视频。

## 本次更新

- **新增「重新下载」按钮**：下载失败的任务，行下方会直接出现「重新下载」；点一下即可按原任务重新下发，不用回到页面重新抓一遍。
- **重试自动换下载通道**：重试时会自动在本机直连和浏览器扩展之间切换，所以「直连被站点拒绝、扩展能下」这类情况不必手动改设置。
- 失败的下载不再需要删掉重建任务；失败原因（网络被断开 / 站点拒绝等）会以中文提示显示在任务行下方，方便判断是不是站点临时限流。

## 下载哪个

| 文件 | 用途 |
| --- | --- |
| `video-downloader-1.1.1-portable.exe` | 程序本体（约 105 MB，免安装，双击即用） |
| `video-downloader-extension-1.1.1.zip` | 浏览器扩展（可选，装了才有「跟随页面 / 抓当前页」） |

## 快速开始

1. 双击 `video-downloader-1.1.1-portable.exe`（第一次启动要解压，慢几秒）。
2. 把媒体直链粘进输入框回车，或拖进窗口 → 开始下载。
3. 关窗口只是缩到右下角托盘，真正退出用托盘菜单「退出」。
4. 下载失败时，在失败任务那一行点「重新下载」即可再试一次（会自动换通道）。

## 可选：装扩展（只有想「跟随页面」才需要）

1. 解压 `video-downloader-extension-1.1.1.zip`，得到 `video-downloader-extension` 文件夹；
2. Edge 打开 `edge://extensions`（Chrome 用 `chrome://extensions`）→ 开启「开发者模式」；
3. 点「加载已解压的扩展程序」→ 选第 1 步那个文件夹；
4. 回到程序，面板显示「浏览器扩展已连接」即成功；之后在浏览器里刷新一下目标页面。

## 说明与限制

- 只支持 **Windows**（打包与托盘行为按 Windows 做）。
- 「跟随页面」依赖浏览器扩展，而 Chrome / Edge 不允许程序静默安装扩展，所以需要手动装一次；不装扩展时，程序依然可以下载直链。
- 只抓「文件」：`blob:` / MSE（HLS、DASH 播放器常见形态）抓不到；站点适配器目前只有 B 站。
- 分离的视频轨 + 音频轨合并成 mp4 需要本机有 ffmpeg（放到 `%APPDATA%\video-downloader\tools\bin\ffmpeg.exe` 或加进 PATH）；没有时会隐藏这些清晰度并说明原因。
- 个别站点有防盗链或限流：表现为直连被重置、扩展也拿不到字节。这种属于对方限制，重试只解决临时性失败；连续快速点重试反而更容易被当成爬虫，建议隔一两分钟只点一次。
- 本项目仅供学习、测试与技术研究使用，请遵守来源网站的服务条款与当地法律。

## 校验（发布者自测结论）

- `pnpm typecheck`：0 错
- `pnpm test`：296 个用例全过（含新增 3 个重试用例）

- `pnpm verify:mux`：真 ffmpeg 合并出同时含 h264 + aac 的 mp4

- exe 的 SHA256 与本地构建产物一致（上传后由 GitHub API digest 复核）
