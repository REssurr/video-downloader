按顺序做一遍即可。每一条都写清「怎么做 → 应该看到什么」。**任何一条与预期不符，就是 bug**，把第几条和截图发我。

前置：`D:\video-downloader` 已 `pnpm install`（或直接用 `release\video-downloader-0.1.0-portable.exe`）。

## A. 不开浏览器扩展，先验证"独立程序"本身

### A1 启动
```powershell
cd D:\video-downloader
pnpm dev
```
- [ ] 出现一个窄长的深色窗口，标题「视频下载器」
- [ ] 面板顶部显示 `● 实时`；下方有输入框和下载列表
- [ ] 面板上 `ffmpeg` 一栏显示「已就绪」（若你把 ffmpeg 放进了 `%APPDATA%\video-downloader\tools\bin\`）
- [ ] 右下角托盘出现本程序图标

### A2 直链下载（不需要扩展）
```powershell
pnpm fixture        # 另开一个终端，起本地验收页
```
1. 把 `http://127.0.0.1:5399/sample.mp4` 粘贴进输入框并回车
2. 等它探测出候选，点下载
- [ ] 列表里出现一条任务，进度条走动，最终变成「已完成」
- [ ] 文件出现在面板显示的下载目录里，能正常播放（3 秒的测试视频）

### A3 拖入链接
- [ ] 在浏览器里打开 `http://127.0.0.1:5399/page.html`，把地址栏的网址**拖进本程序窗口** → 输入框被填上并自动开始探测
- [ ] （说明：拖的是**网址**，不是文件；从资源管理器拖一个 mp4 文件进来不支持，本程序只下载 http/https 地址）

### A4 关窗进托盘（本次新增）
- [ ] 点窗口右上角 ×：窗口消失，**托盘图标还在**
- [ ] 点托盘图标：窗口回来
- [ ] 托盘右键菜单有「显示主窗口 / 导出浏览器扩展… / 退出」
- [ ] 只有托盘菜单「退出」才会真正结束进程（任务管理器里没有 `video-downloader` 残留）

## B. 装扩展，验证"跟随页面"

> 这一段的"扩展装进真 Chrome、真取字节、真落盘"已经由 `scripts/e2e-extension.mjs` 自动跑通（headless Chrome + 真 MV3 扩展 + 真程序，逐字节比对 mp4）。你这里手工过一遍，是为了确认真实浏览器、真实鼠标操作下也成立。

### B1 导出扩展
- [ ] 托盘右键 →「导出浏览器扩展…」→ 弹出说明框，并打开 `%APPDATA%\video-downloader\extension`
- [ ] 该文件夹里有 `manifest.json` 和 `build\background.js`、`build\content.js`

### B2 在浏览器里加载
Chrome 地址栏 `chrome://extensions`（Edge 用 `edge://extensions`）→ 打开「开发者模式」→「加载已解压的扩展程序」→ 选上面的 `extension` 文件夹。
- [ ] 扩展列表里出现「视频下载器 · 浏览器桥」且没有红色错误
- [ ] 回到本程序面板，扩展一栏变成「浏览器扩展已连接」（不再是"扩展还没有看到可读取的页面"）

### B3 抓当前页
1. 浏览器打开 `http://127.0.0.1:5399/page.html`（`pnpm fixture` 起的页面）
2. 切回本程序，点「抓当前页」
- [ ] 列出页面里的视频候选（页面里嵌了一个 mp4）
- [ ] 点下载，文件落盘且能播放

### B4 自动跟随
1. 浏览器停留在 `page.html`，本程序窗口放旁边
2. 在浏览器里刷新页面 / 换到另一个含 mp4 的页面
- [ ] 面板自动刷新候选（不需要再点「抓当前页」）

## C. 合并（有 ffmpeg 时）

> 合并这一步本身已经用真 ffmpeg 自动验证过（见第 0 节）；这里你用真实场景复核一遍。

- [ ] 面板里出现「需要合并音视频轨」的档位时能下载，并在完成后得到有声音的 mp4
- [ ] 把 `%APPDATA%\video-downloader\tools\bin\ffmpeg.exe` 临时改名后重启程序：需要合并的档位**消失**，并有一句说明（而不是下出没声音的文件）

## D. 安全与容错（不需要真站点，快速过一遍）

- [ ] 在浏览器里随便打开一个网站，F12 控制台执行
      `fetch('http://127.0.0.1:47821/video-downloader/api/config.get',{method:'POST'})`
      → 应当被拒绝（CORS / 403），**不能**拿到配置
- [ ] 端口占用：先让别的程序占住 47821，再启动本程序 → 它应换一个端口启动（面板照常可用）
- [ ] 下载中途点取消 → 任务变「已取消」，磁盘上留下 `.part` 而不是半成品最终文件
- [ ] 同名文件再下一次 → 不会覆盖，名字带 `(1)`

## E. 打包产物（本次新增）

- [ ] `release\video-downloader-0.1.0-portable.exe` 存在，双击能直接启动（不弹安装向导）
- [ ] 便携版里托盘菜单「导出浏览器扩展…」同样可用
- [ ] 便携版里下载功能正常（上面 A2 的步骤再走一遍）
